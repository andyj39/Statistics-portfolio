# Andrew Jones: Data Analysis & Simulation Portfolio

Master's graduate (Mathematics, Statistics and Operational Research, Queen's University Belfast, 2026). This repository collects code from my university projects in R and Python.

| Project | What it is | Tools |
|---|---|---|
| [Traffic light simulation](traffic-light-simulation) | Discrete-event simulation comparing fixed and queue-responsive traffic lights in Enniskillen, with an emergency vehicle override | Python, NumPy, SciPy |
| [Bayesian regression and MCMC](bayesian-regression-mcmc) | Gibbs, Metropolis-Hastings and importance sampling written from scratch and compared with MCMCpack | R |
| [COVID-19 Ball Mapper](covid-ball-mapper) | Topological data analysis of COVID-19 data (group project) | R, BallMapper |
| [Healthcare simulation (MSc project)](healthcare-simulation-msc) | (To-do) Summary and demo of my master's project simulating a volunteer first responder scheme for out-of-hospital cardiac arrests across Northern Ireland | R |
